01 · Goal

改造目标与范围

对齐 xx-coding 核心能力，用标准包与自研 agent loop 重写；交互层改为 Python，不再维护 Node/Ink 第二入口。

Before · xx-coding

  • OpenAI Agents SDK + 松散 src/
  • scripts/cli.py 与 npm tui 双入口
  • React/Ink 独立前端栈

After · xcode

  • 纯 Python 包 src/xcode + pyproject.toml
  • 单一 Typer 入口（参考 PaiCLI 模式）
  • prompt-toolkit + rich 作为 TUI

02 · Alignment

03 · Single Entry

一个入口，三种姿态

无子命令进入交互；-p 单次运行；具名子命令留在 CLI。不再分发两套启动脚本。

xcode / python -m xcode → entrypoints.cli → tui | -p | session/doctor → runtime.agent → tools + context

04 · Run

目录与启动

包路径 src/xcode/；数据默认落在 ~/.xcode/。先同步依赖，再 doctor，再进入 TUI。

# 安装
uv sync --extra dev

# 配置 .env（见 .env.example）后
uv run xcode doctor
uv run xcode
uv run xcode -p "列出项目结构"
uv run pytest
